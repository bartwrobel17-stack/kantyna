# Kantyna Wrocław

Strona restauracji Kantyna przy Pawła Włodkowica 23 we Wrocławiu.

Panel właściciela jest obecnie DEMO: logowanie po stronie klienta, galeria w localStorage. Demo: właściciel / kantyna-demo. To nie jest zabezpieczenie produkcyjne. Docelowo należy podmienić adapter na Supabase Auth + Storage bez przebudowy UI.

Projekt: Next.js 16, React 19, TypeScript, CSS, App Router. Gotowy do importu na Vercel. Godziny i menu należy zweryfikować przed publikacją.
